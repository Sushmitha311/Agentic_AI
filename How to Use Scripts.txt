AGENTIC AI PIPELINE - SCRIPT USAGE GUIDE
========================================

This folder contains a portable, read-only requirements-to-test traceability
pipeline. The master orchestrator runs three stages:

  Agent 1: Extracts requirements from DNG or a local Excel/CSV file and
           generates positive, negative, and boundary test scenarios.
  Agent 2: Maps the decoded requirements to test cases in an ETM PDF and
           calculates coverage.
  Agent 3: Converts the traceability JSON into a formatted Excel report.

Live DNG and ETM data is read only. Generated files are written locally to
the workspace folder.

2. PREREQUISITES
----------------

Install Python dependencies:

  python -m pip install openpyxl requests urllib3

Install the Gemini CLI if it is not already available:

  npm install -g @google/gemini-cli

To use the Gemini agent definitions, copy all files from:

  Agentic_AI\agents\

to:

  %USERPROFILE%\.gemini\agents\

For online DNG mode, config.py must be able to resolve oslcquery.exe from the
configured pmt-server installation. Credentials are supplied through
environment variables; do not store them in this folder.


3. OFFLINE PIPELINE
-------------------

Offline mode avoids the DNG query and reads a local Excel or CSV requirements
file. The ETM test-case PDF is still required for traceability mapping.

Open PowerShell and run:

  cd D:\FIT\Agentic_AI\scripts
  python .\agent_0_master_orchestrator.py `
    --offline `
    --input-file "D:\path\MCU_Update_Requirement.xlsx" `
    --section "MCU" `
    --test-pdf "D:\path\Iveco_Mcu_Update.pdf"

The input file may be an .xlsx or .csv file. Replace the example paths with
the actual local paths.


4. ONLINE PIPELINE
------------------

Online mode queries DNG for the latest requirements. Set credentials only in
the current PowerShell session:

  cd D:\FIT\Agentic_AI\scripts
  $env:DNG_USERNAME = "your_username"
  $env:DNG_PASSWORD = "your_password"

Run the orchestrator:

  python .\agent_0_master_orchestrator.py `
    --project "NEO" `
    --component "NEO" `
    --config "DNG NEO Stream" `
    --module "SWRS Update" `
    --section "MCU" `
    --test-pdf "D:\path\Iveco_Mcu_Update.pdf"

The orchestrator options are:

  --project       DNG project area; default is NEO
  --component     DNG component; default is NEO
  --config        DNG configuration or stream; default is DNG NEO Stream
  --module        DNG module title
  --section       Requirement section; default is MCU
  --test-pdf      ETM test-case PDF; required
  --offline       Use a local requirements file instead of DNG
  --input-file    Local Excel or CSV file used with --offline

Show the live command help with:

  python .\agent_0_master_orchestrator.py --help


5. RUN INDIVIDUAL STAGES
------------------------

Use these commands when intermediate files already exist or a stage needs to
be rerun independently.

Agent 1 - requirement decoding:

  python .\agent_1_requirement_understanding.py `
    --offline `
    --input-file "D:\path\requirements.xlsx" `
    --section "MCU"

Agent 2 - traceability mapping:

  python .\agent_2_traceability_mapper.py `
    --req-json "..\workspace\decoded_requirements.json" `
    --test-pdf "D:\path\Iveco_Mcu_Update.pdf" `
    --output "..\workspace\traceability_matrix.json"

Agent 3 - Excel report generation:

  python .\agent_3_excel_report_generator.py `
    --input-json "..\workspace\traceability_matrix.json" `
    --output-excel "..\workspace\traceability_report.xlsx"


6. OUTPUT FILES
---------------

All pipeline outputs are saved in Agentic_AI\workspace\:

  decoded_requirements.json
    Requirement IDs, titles, functional scope, and generated scenarios.

  traceability_matrix.json
    Requirement counts, covered counts, coverage percentage, and linked ETM
    test cases with objectives, steps, and validations.

  traceability_report.xlsx
    Formatted Excel report containing requirement status, mapped test cases,
    and coverage status.


7. INSPECTION AND DIAGNOSTIC SCRIPTS
------------------------------------

These scripts inspect inputs, outputs, or local Gemini logs. They do not run
the complete pipeline.

  Analyze a workbook's headings and MCU section:
    python .\analyze_mcu_sheet.py "D:\path\MCU_Update_Requirement.xlsx"

  Inspect workbook columns and section values:
    python .\check_mcu_columns.py "D:\path\MCU_Update_Requirement.xlsx"

  Summarize generated JSON outputs:
    python .\read_temp_outputs.py

  Inspect local Gemini logs and execution timings:
    python .\parse_logs_workspace.py
    python .\extract_run_timings.py

  DNG_PASSWORD    DNG password for online mode
